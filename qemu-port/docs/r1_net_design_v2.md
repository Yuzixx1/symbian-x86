# R1 TCP/IP design v2 — read-only investigation (no files modified but this doc)

**Architecture:** `netstack.E32` is a normal user process launched by `E32Run` (variant/e32load.cpp:692) as a PE2 image: 1-based ordinals in the IAT (e32load.cpp:436-466) are bound to real `EUSER.DLL` exports (843-861). Layers: e1000 kernel driver (PCI class 02.00; ISR/DFC, TX/RX rings in a named global chunk) -> netstack user process (ARP, IPv4, ICMP, UDP, TCP) -> `!SocketServer` CServer2 IPC service -> user apps. Sockets are IPC function numbers, not new EUSER ordinals.
**EUSER ordinals present (bx86gcc/euseru.def):** RChunk 902-913, RThread 1153-1161, RProcess 1313-1330, RSessionBase 1547-1550/1991-1992, User::WaitForRequest 604, UserSvr::FsRegisterThread 1221, memcpy 1953 (~2503 total). Runtime uses execs directly: timer 133/53, chunk 107/109, IPC 34/35/36/65/77/128, request-semaphore `int 0x20` (start.S:10-14).
**Missing:** no RSocket/RSocketServ/TInetAddr/RHostResolver/ESOCK/INET exports anywhere — genuine Symbian sockets live in ESOCK.DLL (absent). Add zero EUSER ordinals; expose `socket/bind/connect/send/recv/close` (+listen/accept) as `ipc_call` function numbers on `!SocketServer` (fd = subsession), payload via `ipc_read8`/`ipc_write8` slots.
**RX flow:** e1000 DMA -> ISR ACK + DFC enqueues frame into global chunk ring -> netstack reads via `chunk_base`/`ipc_read8` -> ARP cache resolve -> IPv4 checksum/TTL/defrag -> demux to ICMP echo, UDP or TCP by (proto,srcIP,srcPort,dstIP,dstPort) -> per-socket RX queue -> `ipc_write8` + request signal completes the client's pending recv. **TX:** reverse — client send builds Ethernet+ARP/IP+TCP in chunk, driver DFC posts to e1000 TX ring.
**DNS:** UDP client (port 53) inside netstack; servers from DHCP option 6 or static; 12-byte header + QNAME/QTYPE=A, 16-bit ID matches outstanding query table; parse A answers into a TTL cache; 2 s timeout with retry; exposed as `gethostbyname` socket API call.
**DHCP:** UDP 68(client)/67(server); DORA — broadcast DISCOVER from 0.0.0.0:68 with MAC+xid on 255.255.255.255:67, then OFFER -> REQUEST -> ACK; install IP/mask/gateway/DNS(6)/lease(51); T1/T2 renewal via exec 133 timers; ARP-probe for address conflicts before use.
**Build/tests:** add netstack + socket client to user.mk and FAT staging in r1_qemu_smoke.py; add explicit `-netdev user,id=n0 -device e1000,netdev=n0`; QEMU regressions for ARP, ICMP ping, DHCP lease, DNS lookup and TCP echo. Keep kernelhwsrv/ frozen; no exec-table patches needed.
