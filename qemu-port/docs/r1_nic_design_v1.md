# R1 NIC design v1 — D-06 findings (read-only)

- QEMU hardware: smoke test uses `-M q35` with **no `-netdev`/`-nic`** (tools/r1_qemu_smoke.py:144-154), so the q35 default NIC (Intel e1000e/e1000, PCI class 02.00 ethernet, 8086:10xx) is present but has no host backend — link down, no host traffic. virtio-net/pcnet appear only if explicitly added. `PciList()` already prints class 02 as "ethernet"/"network" (qemu_pci.cpp:69).
- NIC driver code: **none**. No e1000/virtio/pcnet driver, no MAC/ARP/IP/TCP/UDP, no RX/TX ring, no socket API. grep across qemu-port finds "net" only in docs (PROJECT_GOAL/roadmap: NIC drivers "Not started"). PCI scanner has `PciFindClass(02,00)` capability but no consumer.
- Interrupt infra: usable. i8259 PIC remapped to 0x20/0x28 (qemu_assp.cpp:51), 16-slot `Interrupt::Bind`/`Enable`/`Clear` dispatcher (qemu_variant_int.cpp:46-103), 8259 ISR-driven `X86IrqDispatcher` + EOI (:110-145). Only IRQ0/1/4 bound (:217-223); legacy PCI INTA#->IRQ linkage (PCI 0x3C interrupt line/pin) is **not** wired up — must add. e1000 uses MSI-X or INTx; start with INTx + PCI interrupt-line register.
- Templates: storage/USB are all **polled** (qemu_ata/ahci/usb/usb_ohci), no IRQ wiring — good bring-up base for a polled e1000 MMIO RX/TX first, then add INTx. BAR mapping pattern: `PciRead32(BAR)` + enable MEM|bus-master via command reg (qemu_ahci.cpp:248-254). Identity-mapped RAM means virtual==physical for DMA buffers.
- Init: ckernel.cia is pure asm exception/trap glue (no device probe); `Asic::Init1`/`Init3` (qemu_variant_asic.cpp) + shell commands (`pci`,`ata`,`usb`) drive probing. Makefile: variant .cpp -> build/*.o -> KERNFULL_OBJS (Makefile:220-271); add qemu_nic.o there and a `nic` shell command.
- Next steps: (1) `PciFindClass(02,00)` + read vendor/device BAR; (2) add `-netdev user,id=n0 -device e1000,netdev=n0` to smoke test; (3) e1000 init: MEM/BM enable, BAR MMIO, reset, RX/TX descriptor rings, MAC; (4) polled TX/RX of one ARP frame; (5) bind PCI IRQ via 0x3C + Interrupt::Bind, enable in INTx; (6) ARP/IPv4/ICMP echo, then UDP/TCP + sockets (N-01..N-04).
